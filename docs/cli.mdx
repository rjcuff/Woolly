| Command | What it does |
| --- | --- |
| `woolly remember <text>` | Save a fact |
| `woolly recall <query>` | Search your memories |
| `woolly list` | Show current memories |
| `woolly show <id>` | Show one memory in full |
| `woolly forget <id>` | Move a memory to the trash |
| `woolly restore <id>` | Bring a memory back from the trash |
| `woolly trash` | List the trash, or delete it for good with `--empty` |
| `woolly import <chatgpt\|claude> <file>` | Import facts from your chat history |
| `woolly profile` | Summary of everything Woolly knows about you |
| `woolly ui` | Open the review page in your browser |
| `woolly conflicts` | Review facts that disagree |
| `woolly resolve <id>` | Keep this version as the current fact |
| `woolly serve` | Run the local HTTP API and review page |
| `woolly mcp` | Run as an MCP server for AI apps |
| `woolly doctor` | Check your setup |
| `woolly version` | Print the version |

IDs can be shortened to any unique prefix, like `woolly show 20261110-1500`.

## remember

```sh
woolly remember "Moved to Denver in October" --key user.location --tags home
```

| Flag | Meaning |
| --- | --- |
| `--key` | Names the fact so a newer one can replace it |
| `--tags` | Comma-separated tags |
| `--source` | `user` (default), `agent` or `import` |
| `--allow-secret` | Save even if it looks like a password or API key |
| `--json` | Print the result as JSON |

## recall

```sh
woolly recall "where do I live" -n 3
```

| Flag | Meaning |
| --- | --- |
| `-n` | How many results, default 5 |
| `--all` | Include superseded and conflicting memories |
| `--json` | Print results as JSON |

## import

```sh
woolly import chatgpt ~/Downloads/export.zip --dry-run
```

| Flag | Meaning |
| --- | --- |
| `--dry-run` | Show what would be imported without saving |

See [Import your history](/docs/import).

## profile

```sh
woolly profile
```

```md
# About me

## Facts

- Moved to Denver in October

## Preferences

- I prefer short answers
```

Add `--json` for JSON.

## forget, restore and trash

```sh
woolly forget 20261110-1500
woolly trash
woolly restore 20261110-1500
woolly trash --empty
```

Forgetting moves a memory to the trash. It's only gone for good after `woolly trash --empty`.

## list

```sh
woolly list --all
```
