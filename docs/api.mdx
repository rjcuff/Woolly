title: HTTP API

Building in Python? The [Python package](/docs/python) wraps this API.

Start the server:

```sh
woolly serve
```

It also serves the review page at `http://127.0.0.1:11435`. It listens on `127.0.0.1:11435`, right next to Ollama's `11434`. It only accepts requests from your own machine and blocks requests from websites.

## Authentication

Every request except `/api/version` needs the token stored in `~/.woolly/token`. Send it as a Bearer token:

```sh
TOKEN=$(cat ~/.woolly/token)
curl -H "Authorization: Bearer $TOKEN" localhost:11435/api/memories
```

The review page gets the token automatically when you open it with `woolly ui`.

## Remember

```sh
curl -X POST localhost:11435/api/remember \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"content": "Prefers dark mode", "key": "ui.theme"}'
```

## Recall

```sh
curl -X POST localhost:11435/api/recall \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"query": "dark mode", "limit": 5}'
```

```json
{
  "mode": "keyword",
  "results": [
    { "memory": { "id": "…", "content": "Prefers dark mode", "key": "ui.theme" }, "score": 1.05 }
  ]
}
```

## All endpoints

| Method | Path | Body |
| --- | --- | --- |
| `POST` | `/api/remember` | `content`, plus optional `key`, `tags`, `source`, `project` |
| `POST` | `/api/recall` | `query`, plus optional `limit`, `include_all`, `project` |
| `GET` | `/api/memories` | Add `?all=1` for everything, `?project=acme` for one project |
| `GET` | `/api/memories/{id}` | |
| `PATCH` | `/api/memories/{id}` | Any of `content`, `key`, `tags`, `project` |
| `DELETE` | `/api/memories/{id}` | Moves the memory to the trash |
| `GET` | `/api/trash` | |
| `POST` | `/api/restore` | `id` |
| `DELETE` | `/api/trash` | Empties the trash for good |
| `GET` | `/api/profile` | Add `?format=markdown` for Markdown |
| `GET` | `/api/conflicts` | |
| `POST` | `/api/resolve` | `keep_id` |
| `GET` | `/api/activity` | Add `?app=cursor` for one app, `?limit=50` for fewer |
| `GET` | `/api/version` | |

## Name your app

Send an `X-Woolly-Client` header with your app's name. Memories you save show "via" that name, and your app shows up by name in the activity log.

```sh
curl -s localhost:11435/api/remember \
  -H "Authorization: Bearer $(cat ~/.woolly/token)" \
  -H "X-Woolly-Client: My notes app" \
  -d '{"content": "Reads on the train"}'
```
