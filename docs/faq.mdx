---
title: FAQ
description: Common questions about Woolly.
---

<Accordions>
<Accordion title="Do I need Ollama?">
No. Woolly works fully on its own. Ollama only adds search by meaning. See [Using Ollama](/docs/ollama).
</Accordion>
<Accordion title="Does Woolly send my data anywhere?">
No. There is no cloud, no telemetry and no account. Your memories stay in `~/.woolly` on your computer.
</Accordion>
<Accordion title="How is this different from ChatGPT or Claude memory?">
Those memories live inside one app, on someone else's servers. Woolly is shared by every app you connect, and it lives on your machine in files you can read.
</Accordion>
<Accordion title="Can I edit memories by hand?">
Yes. Each memory is a Markdown file. Edit it in any editor and Woolly picks up the change.
</Accordion>
<Accordion title="How do I delete everything?">
Delete the `~/.woolly` folder.
</Accordion>
<Accordion title="Is it free?">
Yes. Woolly is open source under the MIT license.
</Accordion>
</Accordions>
