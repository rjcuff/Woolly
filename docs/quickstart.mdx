## Install Woolly

<Tabs items={['Mac app', 'macOS and Linux', 'Homebrew', 'Windows', 'Go', 'From source']}>
  <Tab value="Mac app">
    [Download Woolly for Mac](https://github.com/rjcuff/woolly/releases/latest/download/Woolly-mac.dmg), open it and drag Woolly to Applications. It works on Apple Silicon and Intel Macs, runs Woolly in the background and lives in your menu bar.

    To also get the `woolly` command in your terminal, run the macOS and Linux install.
  </Tab>
  <Tab value="macOS and Linux">
    ```sh
    curl -fsSL https://usewoolly.com/install.sh | sh
    ```
  </Tab>
  <Tab value="Homebrew">
    ```sh
    brew install rjcuff/tap/woolly
    ```
  </Tab>
  <Tab value="Windows">
    In PowerShell:

    ```powershell
    irm https://usewoolly.com/install.ps1 | iex
    ```
  </Tab>
  <Tab value="Go">
    ```sh
    go install github.com/rjcuff/woolly/cmd/woolly@latest
    ```
  </Tab>
  <Tab value="From source">
    ```sh
    git clone https://github.com/rjcuff/woolly
    cd woolly && make install
    ```
  </Tab>
</Tabs>

Check that it worked:

```sh
woolly version
```

## Save a memory

```sh
woolly remember "I prefer tabs over spaces" --key code.indent
```

The `--key` names the fact. Use one for anything that can change, like where you live or which database a project uses.

## Get it back

```sh
woolly recall "tabs or spaces"
```

```txt
1.05  [20261110-150029-92f9ddf6] I prefer tabs over spaces (key: code.indent; source: user; 2026-11-10)
(keyword search; run 'woolly doctor' to enable semantic search)
```

With [Ollama](/docs/ollama) running, Woolly also searches by meaning, so "what indentation do I like" finds it too.
## Connect your AI

```sh
woolly connect
```

This adds Woolly to Claude Code, Claude Desktop, Cursor, VS Code, Windsurf, Codex, Gemini CLI, LM Studio and opencode, whichever you have. Now they can remember and recall on their own. See [Connect your apps](/docs/connect).

## Share project memory with your team

In a git repo:

```sh
woolly init
```

Commit `.woolly/`, and every teammate's AI tools read and update the same notes about the project. See [Project memory](/docs/project-memory).

## Keep it running

```sh
woolly service install
```

Woolly now runs in the background and starts when you log in, like Ollama. The review page, the API and the [proxy](/docs/proxy) are always ready. Stop it with `woolly service uninstall`.
