title: Connect your apps
description: Use Woolly from Claude Code, Claude Desktop, Cursor and any other MCP app.

Woolly speaks MCP, the Model Context Protocol. Any app that supports MCP can use it as its memory. For Ollama and apps that don't support MCP, use the [proxy](/docs/proxy). To learn what happens behind the scenes, see [How MCP works](/docs/mcp).

## One command

```sh
woolly connect
```

Woolly finds the AI apps on your computer and adds itself to each one:

```txt
Connecting Woolly (/opt/homebrew/bin/woolly)

  ✓ Claude Code     connected
  ✓   at startup    loads your profile when a session starts
  ✓ Claude Desktop  connected
  ✓ Cursor          connected
  - Windsurf        not found
  ✓ VS Code         connected

Restart Claude Desktop to load the change.
```

It works with Claude Code, Claude Desktop, Cursor, VS Code, Windsurf, Codex, Gemini CLI, LM Studio and opencode. It only adds a `woolly` entry and keeps the rest of each config as it was. Before it changes a file, it saves a copy next to it ending in `.woolly-backup`.

| Command | What it does |
| --- | --- |
| `woolly connect` | Connect every app it finds |
| `woolly connect cursor vscode` | Connect only these apps |
| `woolly connect --dry-run` | Show what would change without changing anything |
| `woolly disconnect` | Remove Woolly from the apps again |

App names: `claude-code`, `claude-desktop`, `cursor`, `vscode`, `windsurf`, `codex`, `gemini`, `lmstudio`, `opencode`.

Claude Code and Codex are set up through their own `claude mcp add` and `codex mcp add` commands. The others are set up by editing their config files.

## Memory that loads by itself

In most apps, the AI has to decide to call Woolly before it knows anything about you. For Claude Code, `woolly connect` also adds a startup hook, so every session starts with your profile and the notes about the project you're in. You don't have to ask.

The hook runs `woolly context`. It prints your profile and the memories for the current project, which is the name of the git repo or folder. Other projects' notes are left out. See [Projects](/docs/projects). It stays under Claude Code's 10,000 character limit for startup context. To see exactly what Claude Code gets, run it yourself:

```sh
woolly context
```

The hook is saved in `~/.claude/settings.json`, and `woolly disconnect` removes it. If you'd rather not have it, delete the `SessionStart` entry that runs `woolly context`.

If a config file has comments, Woolly won't rewrite it. It prints the lines to paste in yourself instead.

## Set it up by hand

Prefer to edit the configs yourself, or using another MCP app? Here's what `woolly connect` adds.

### Claude Code

```sh
claude mcp add --scope user woolly -- woolly mcp
```

To load your profile at startup, add this to `~/.claude/settings.json`:

```json title="~/.claude/settings.json"
{
  "hooks": {
    "SessionStart": [
      {
        "matcher": "startup|clear|compact",
        "hooks": [{ "type": "command", "command": "woolly context --app claude-code", "timeout": 10 }]
      }
    ]
  }
}
```

### Claude Desktop

The easiest way: download [woolly.mcpb](https://github.com/rjcuff/woolly/releases/latest/download/woolly.mcpb) and double-click it. Claude Desktop installs Woolly as an extension, with nothing else to set up. It works on macOS, Windows and Linux.

Or open **Settings → Developer → Edit Config** and add Woolly:

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "woolly": { "command": "woolly", "args": ["mcp"] }
  }
}
```

Restart Claude Desktop.

### Cursor

Add the same block to `~/.cursor/mcp.json`:

```json title="~/.cursor/mcp.json"
{
  "mcpServers": {
    "woolly": { "command": "woolly", "args": ["mcp"] }
  }
}
```

### VS Code

VS Code uses `servers` instead of `mcpServers`. Run **MCP: Open User Configuration** and add:

```json title="mcp.json"
{
  "servers": {
    "woolly": { "type": "stdio", "command": "woolly", "args": ["mcp"] }
  }
}
```

<Callout title="Command not found?">
  If the app can't find `woolly`, use the full path. Run `which woolly` to get it.
</Callout>

## What your AI can do

| Tool | What it does |
| --- | --- |
| `remember` | Save a fact |
| `recall` | Search your memories |
| `get_profile` | Get a summary of what Woolly knows about you |
| `list_memories` | List current memories |
| `forget` | Move a memory to the trash, only when you ask |
| `resolve_conflict` | Keep one version of a disputed fact |

Woolly also tells the AI to recall context at the start of a task, and to mark facts it guessed as guesses. See [How MCP works](/docs/mcp) for an example.
