# Roadmap

Woolly's goal: the best memory layer that runs entirely on your own devices.

## Shipped in 0.9

- **Smart memory:** `woolly learn` picks out facts with a model running in Ollama, replaces older facts on the same subject and skips repeats.
- **Sync:** `woolly sync` keeps your devices in step over your own network, encrypted, with no cloud.
- Builds for 32-bit Raspberry Pi OS.

## Next

- Run the LOCOMO memory benchmark that cloud memory services publish, and post Woolly's scores.
- Find devices on the network automatically instead of typing an address.
- Use the model to merge near-duplicates and summarize long histories.
- A desktop app that installs Woolly, keeps it running and shows your memories.
- A JavaScript package.
